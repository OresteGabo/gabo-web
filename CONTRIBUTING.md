# Contributing to Gabo

This project is a **private repository**.\
Access is granted only to authorized developers of **Gabo Technology
Ltd.**

------------------------------------------------------------------------

## 🧭 Development Standards

### Type Safety

-   Use **TypeScript strictly**
-   Avoid the `any` type at all costs

### Component Architecture

-   Every UI element must be a separate file in:

```{=html}
<!-- -->
```
    /src/component

### Commit Messages

Use descriptive headers such as:

-   `feat: add investor data table`
-   `fix: navbar mobile alignment`
-   `refactor: optimize animation rendering`

### Performance

-   Ensure all images are optimized
-   Prioritize fast loading for users in the **East African market**

------------------------------------------------------------------------

## 🌿 Branching Strategy

  Branch           Purpose
  ---------------- --------------------------------
  `main`           Production-ready code only
  `dev`            Active integration branch
  `feature/name`   Individual feature development
